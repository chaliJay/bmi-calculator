BIM Calculator — Vite + React
A modern, fast, and user‑friendly BIM (Body Mass Index) Calculator built using React and Vite.
This project is designed to be simple, responsive, and easy to understand — ideal for beginners learning React or anyone who wants a lightweight BMI tool.-

 Features
 Vite-powered development for instant hot reloads

 Modern React UI with clean components

 Fully responsive layout for mobile and desktop

 Real-time BMI calculation

 Clear result categories (Underweight, Normal, Overweight, Obese)

 Easy-to-read code structure for learning and extending
